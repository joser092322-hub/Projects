The goal of the project was to use the data from the `BolsaFamilia.csv` file to look at Bolsa Família payments.
The program was made so that you can choose a state and a city and, with that, find out how many payments and
how much money were received in Brazil, in the state, and in the city you selected. Some work was also done to
see the cities in the chosen state, showing which one received the most and which one received the least money
in total.

This project was done this way to help analyze the large amount of data in the CSV file. The program reads the data
one by one, separates the column information, converts the money into the proper format, and does the calculations
and counts it needs. This way, the raw data from the file turns into more organized information, making it easy 
to see how the payments were distributed and to compare the money that different cities received.
